# CDK TypeScript プロジェクトへようこそ

これは TypeScript で CDK 開発を行うための空のプロジェクトです。

`cdk.json` ファイルは、CDK ツールキットに対して your app をどのように実行するかを指示します。

## 便利なコマンド

* `npm run build`   TypeScript を JavaScript にコンパイル
* `npm run watch`   変更を監視してコンパイル
* `npm run test`    Jest ユニットテストを実行
* `npx cdk deploy`  デフォルトの AWS アカウント/リージョンにスタックをデプロイ
* `npx cdk diff`    デプロイ済みのスタックと現在の状態を比較
* `npx cdk synth`   CloudFormation テンプレートを出力
