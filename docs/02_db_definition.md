# 🗄️ データベース（テーブル）定義書

本システム（JavaEats）で使用する主要な5テーブルの定義です。
現在の Spring Boot バックエンドで実際に定義されている DDL（`schema.sql`）に基づき、最新のテーブル構造に合致させた構成となっています。

---

## 1. users (ユーザー情報)

ユーザー（顧客）のプロフィールおよびサービス固有の情報を保持するテーブルです。認証情報（メールアドレス・パスワード）は AWS Cognito 側で管理されるため、このテーブルには保持しません。

| 論理名 | 物理名 | データ型 | PK | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| ユーザーID | id | VARCHAR(50) | ◯ | ◯ | AWS Cognito の一意識別子（`sub`）を直接格納します。 |
| ユーザー名 | user_name | VARCHAR(50) | | ◯ | ニックネーム・表示用のお名前 |
| ランクコード | rank_code | INT | | ◯ | 1:一般, 2:プレミアム, 3:VIP（ランクはJavaで計算するため数値のみ保持） |
| 郵便番号 | zip_code | VARCHAR(10) | | | 配送先住所の補完用 |
| 住所 | address | VARCHAR(200) | | | 配送先住所 |
| 電話番号 | phone_number | VARCHAR(20) | | | 連絡用電話番号 |

---

## 2. categories (カテゴリマスタ)

商品のカテゴリ情報を管理するマスタテーブルです。

| 論理名 | 物理名 | データ型 | PK | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| カテゴリID | id | INT | ◯ | ◯ | AUTO_INCREMENT |
| カテゴリ名 | category_name | VARCHAR(50) | | ◯ | |

---

## 3. shops (店舗マスタ)

加盟店（店舗）の情報を管理するマスタテーブルです。店舗が特定のカテゴリ（和食、中華、洋食等）に紐付きます。

| 論理名 | 物理名 | データ型 | PK | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| 店舗ID | id | INT | ◯ | ◯ | AUTO_INCREMENT |
| 店舗名 | shop_name | VARCHAR(100) | | ◯ | |
| カテゴリID | category_id | INT | | ◯ | 外部キー（`categories.id`）に相当するカテゴリID |

---

## 4. items (商品マスタ)

各店舗で提供される商品を管理するマスタテーブルです。

| 論理名 | 物理名 | データ型 | PK | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| 商品ID | id | INT | ◯ | ◯ | AUTO_INCREMENT |
| 店舗ID | shop_id | INT | | ◯ | 外部キー（`shops.id`）に相当する店舗ID |
| 商品名 | item_name | VARCHAR(100) | | ◯ | |
| 価格 | price | INT | | ◯ | |
| 画像パス | image_path | VARCHAR(200) | | ◯ | |

---

## 5. orders (注文トランザクション)

ユーザーからの注文履歴を記録するトランザクションテーブルです。注文時点の正確な情報を保持するため、当時の商品単価や、送料・割引といった実務に即した情報が格納されます。

| 論理名 | 物理名 | データ型 | PK | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| 注文ID | id | INT | ◯ | ◯ | AUTO_INCREMENT |
| ユーザーID | user_id | VARCHAR(50) | | ◯ | 注文を行ったユーザーの Cognito `sub` （`users.id` に紐付く） |
| 商品ID | item_id | INT | | ◯ | 購入した商品のID（`items.id` に紐付く） |
| 数量 | quantity | INT | | ◯ | 購入個数 |
| 購入時単価 | order_price | INT | | ◯ | 注文時点の `items.price` を記録 |
| 送料 | shipping_fee | INT | | ◯ | |
| 割引額 | discount | INT | | ◯ | ランク等による割引額 |
| 支払合計額 | total_price | INT | | ◯ | 最終的な支払い総額 |
| 注文日時 | order_date | DATETIME | | ◯ | 注文が行われた日時 |
