# 💻 画面およびビジネスルール仕様書

## 1. 共通ビジネスルール
本システム全体で適用される計算・判定ルールです。

### 1.1 配送料の計算
* **基本配送料:** 500円
* **送料無料条件:** 注文する商品の「小計（単価 × 数量）」が **3,000円以上** の場合、配送料は 0円 となる。

### 1.2 会員ランクと割引
ユーザーのこれまでの「累計注文回数」と「累計注文金額」に応じて、以下の条件でランクが決定・昇格し、注文時に割引が適用される。
※昇格判定は「注文完了時」に行われる。

| ランクコード | ランク名 | 昇格条件 (回数 AND 累計金額) | 注文時の割引額 |
| :---: | :--- | :--- | :--- |
| 1 | 一般 | 初期状態 | 0円 |
| 2 | プレミアム | 3回以上 かつ 5,000円以上 | 300円引き |
| 3 | VIP | 5回以上 かつ 10,000円以上 | 500円引き |

### 1.3 最終支払金額の計算式
`最終支払金額 = (商品単価 × 数量) + 配送料 - ランク割引額`
※ただし、計算結果が0円を下回る場合は、最終支払金額を0円とする。
